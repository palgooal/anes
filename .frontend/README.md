# الواجهة الأمامية (Tailwind CSS v4)

## الصفحات
| الصفحة | الملف | ملف التنسيق المصدر | الناتج |
|---|---|---|---|
| الموقع العام | `index.html` | `src/input.css` | `dist/style.css` |
| لوحة المرشد | `guide-dashboard.html` | `src/dashboard.css` | `dist/dashboard.css` |

افتح أي صفحة مباشرة في المتصفح، فملفات التنسيق مبنية وجاهزة.
الألوان والخطوط والوضع الليلي مشتركة بين كل الصفحات في `src/theme.css`.

## التعديل على التنسيق
1. ثبّت الحزم مرة واحدة:
   ```bash
   npm install
   ```
2. أثناء العمل (يعيد بناء ملف التنسيق تلقائيًا عند كل حفظ):
   ```bash
   npm run watch            # الموقع العام
   npm run watch:dashboard  # لوحة المرشد
   ```
3. قبل الرفع (يبني الصفحتين بنسخة مضغوطة):
   ```bash
   npm run build
   ```

## هيكل الملفات
- `src/theme.css`: الألوان والخطوط ونقاط الشاشات والوضع الليلي، مشتركة بين كل الصفحات.
- `src/input.css`: تنسيق الموقع العام.
- `src/dashboard.css`: تنسيق لوحة المرشد. لونها الأساسي `--role`، وتستخدمه في الكلاسات `bg-role` و`text-role`.
  - `@layer base`: تنسيق العناصر العامة والمتغيرات، ومنها الوضع الليلي.
  - `@layer components`: مكوّنات الموقع (`.btn` و`.card` و`.svc`...) مكتوبة بـ `@apply`، لأن JavaScript يولّد هذه الكلاسات.
- `index.html`: الصفحة، وتستخدم كلاسات Tailwind مباشرة بدل `style="..."`.
- `dist/`: ملفات التنسيق المبنية، لا تعدّلها يدويًا.

## ملاحظات
- الألوان معرّفة كمتغيرات CSS في `:root`، مثل `--spirit` و`--accent`، ومنها تأتي كلاسات Tailwind. لذلك يكفي تغيير اللون في مكان واحد ليتغير في كل الموقع وفي الوضع الليلي.
- لم يُستخدم Preflight (إعادة الضبط في Tailwind) للحفاظ على التصميم الأصلي كما هو.
- كلاس شبكة البطاقات صار اسمه `.cards` بدل `.grid`، حتى لا يتعارض مع كلاس Tailwind `grid`.
