# الواجهة الأمامية (Tailwind CSS v4)

## الصفحات
| الصفحة | الملف | ملف التنسيق المصدر | الناتج |
|---|---|---|---|
| الموقع العام | `index.html` | `src/input.css` | `dist/style.css` |
| لوحة المرشد | `guide-dashboard.html` | `src/dashboard.css` | `dist/dashboard.css` |
| صفحة المستفيد (المريض أو المرافق) | `patient-portal.html` | `src/dashboard.css` | `dist/dashboard.css` |
| لوحة المستشار الفقهي | `fiqh-dashboard.html` | `src/dashboard.css` | `dist/dashboard.css` |
| لوحة الإدارة | `admin-dashboard.html` | `src/dashboard.css` | `dist/dashboard.css` |
| دخول المستفيد | `login.html` | `src/auth.css` | `dist/auth.css` |
| دخول فريق العمل | `staff-login.html` | `src/auth.css` | `dist/auth.css` |

افتح أي صفحة مباشرة في المتصفح، فملفات التنسيق مبنية وجاهزة.
الألوان والخطوط والوضع الليلي مشتركة بين كل الصفحات في `src/theme.css`.

## التعديل على التنسيق
1. ثبّت الحزم مرة واحدة:
   ```bash
   npm install
   ```
2. أثناء العمل (يعيد بناء ملف التنسيق تلقائيًا عند كل حفظ):
   ```bash
   npm run watch            # الموقع العام
   npm run watch:dashboard  # كل اللوحات
   npm run watch:auth       # شاشتا الدخول
   ```
3. قبل الرفع (يبني كل الصفحات بنسخة مضغوطة):
   ```bash
   npm run build
   ```

## هيكل الملفات
- `src/theme.css`: الألوان والخطوط ونقاط الشاشات والوضع الليلي، مشتركة بين كل الصفحات.
- `src/input.css`: تنسيق الموقع العام.
- `src/dashboard.css`: تنسيق كل اللوحات (المرشد، المستفيد، المستشار الفقهي، الإدارة)، فهي من نفس القالب وتختلف فقط في المتغير `ROLE` داخل الصفحة. لونها الأساسي `--role`، وتستخدمه في الكلاسات `bg-role` و`text-role`.
  - `@layer base`: تنسيق العناصر العامة والمتغيرات، ومنها الوضع الليلي.
  - `@layer components`: مكوّنات الموقع (`.btn` و`.card` و`.svc`...) مكتوبة بـ `@apply`، لأن JavaScript يولّد هذه الكلاسات.
- `src/auth.css`: تنسيق شاشتي الدخول. صُمّمتا من الصفر بكلاسات Tailwind مباشرة في HTML، وتستخدمان Tailwind كاملًا مع Preflight.
- `auth.js`: منطق مشترك لشاشتي الدخول: خانات الرمز، والعدّاد، وإظهار كلمة المرور.
- `index.html`: الصفحة، وتستخدم كلاسات Tailwind مباشرة بدل `style="..."`.
- `dist/`: ملفات التنسيق المبنية، لا تعدّلها يدويًا.

## ملاحظات
- الألوان معرّفة كمتغيرات CSS في `:root`، مثل `--spirit` و`--accent`، ومنها تأتي كلاسات Tailwind. لذلك يكفي تغيير اللون في مكان واحد ليتغير في كل الموقع وفي الوضع الليلي.
- لم يُستخدم Preflight (إعادة الضبط في Tailwind) للحفاظ على التصميم الأصلي كما هو.
- كلاس شبكة البطاقات صار اسمه `.cards` بدل `.grid`، حتى لا يتعارض مع كلاس Tailwind `grid`.

## شاشات الدخول (نموذج تجريبي)
- **دخول المستفيد** (`login.html`): شاشة واحدة للمريض والمرافق. رقم الجوال، ثم رمز واتساب، ثم تُفتح `patient-portal.html`. النظام يعرف من الرقم هل صاحبه مريض أم مرافق.
  أي رقم يبدأ بـ 05 مسجّل كمريض، و`0511111111` رقم مرافق، و`0500000000` غير مسجّل. الرمز الصحيح `1234`.
- **دخول الفريق** (`staff-login.html`): البريد وكلمة المرور، ثم التحقق الثنائي، ثم تُفتح لوحة الشخص حسب دوره.
  كلمة المرور `demo1234` والرمز `1234`. الحسابات: `guide@` و`fiqh@` و`admin@` و`pending@` و`suspended@demo.sa`.
- الحالات المصمّمة: رقم غير مسجّل، رمز خاطئ مع عدد المحاولات، إيقاف مؤقت بعد ٥ محاولات، إعادة إرسال الرمز بعد دقيقة، نسيت كلمة المرور، حساب قيد المراجعة، حساب موقوف، طلب الانضمام، وانتهاء الجلسة (`?expired=1`).
- زر «خروج» في كل اللوحات يعيد إلى شاشة الدخول المناسبة.
- رقم واتساب الخدمة يُضاف في `WA_NUMBER` داخل `auth.js`.
